# DIRECTION-NOTE · kimi · Round 3

三个结构性互异构想（ASCII 草图），选择其一实现。

## 方向 A · 注意队列右栏

```
┌──────────────────────────────┬───────────┐
│ 顶带：目标 · 阶段 · 运行控制 · 授权印章          │
├──────────────────────────────┤ 待处理 1   │
│                              │ 审批卡     │
│      对话流（滚动）            ├───────────┤
│      思路折叠 / 工具台账        │ 进行中     │
│                              │ 证据 列表  │
├──────────────────────────────┤ 已完成     │
│ Composer                     │           │
└──────────────────────────────┴───────────┘
```
右栏整体按 Tutti 队列组织。问题：Diff 在队列里只是列表项，要看全文必须再弹层，证据被降级；右栏宽度做不了可读 Diff。

## 方向 B · 召唤式覆盖层

```
┌──────────────────────────────────┬─┐
│ 顶带：目标 · 阶段 · 印章              │█│ ← 细条：
│                                  │◆│   待审批/失败
│      对话（唯一常驻面，居中单栏）      │○│   等状态符
│                                  │ │
│      Diff/审批 → 点击细条后抽屉覆盖   │ │
├──────────────────────────────────┤ │
│ Composer                          │ │
└──────────────────────────────────┴─┘
```
对话沉浸感最强。问题：证据默认不可见，违背「证据诚实 / 产物优先」——产物是验收对象，不该需要召唤；审批藏在细条后也削弱「控制权清楚」。

## 方向 C · 对话—审阅分屏工作台（选定）

```
┌──────────────────────────────────┬──────────────┐
│ 顶带：目标·阶段·暂停/终止·原型标识·授权印章         │
├──────────────────────────────────┤ ◆ 待审批卡(常驻)│
│                                  │  允许/调整/拒绝 │
│      对话流（左，约 6 成宽）         ├──────────────┤
│      思路折叠 · 工具台账            │ 页签:        │
│                                  │ 审阅Diff|上下文│
│                                  │ |验证         │
│                                  │ (证据区滚动)   │
├──────────────────────────────────┤              │
│ Composer                          │              │
└──────────────────────────────────┴──────────────┘
```
左对话、右审阅，像结对编程：左边说话，右边落锤。审批钉在证据区之上常驻；Diff 默认即开（0 步），上下文/验证一页签切换（1 步）。

## 选择与放弃原因

- **选 C**：产品原则里「产物优先」「证据诚实」要求 Diff/测试是一等表面；分屏让对话与验收并列持续可见，审批钉顶保证控制不失踪。空间叙事清楚：对话驱动，证据收口。
- **弃 A**：队列把证据压成列表项，Diff 必须二次展开，验收路径变长；同形分组条目正是反例 B 的温床。
- **弃 B**：覆盖层把证据藏到默认不可见，与「首屏即见审批摘要+Artifact 摘要」冲突，也让首次进入的用户失去环境感知。

## 视觉主张（配合 C）

暖纸（#F6F2EA）+ 墨字 + 朱砂（#B43A24）：授权状态做成「印章」（未授予=空心描边章，verified=实心落章，文字同步变化，不只靠颜色）；衬线标题（Georgia/宋体系）配无衬线正文、等宽代码；对话用编辑式transcript（说话人小标签+发丝线），不用气泡。状态词全部带符号+文字双编码。
