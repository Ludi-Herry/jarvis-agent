# Round 3 内部方向探索 · ZCode

> 编码前完成。三个构想在空间组织、Artifact 进入方式、人工介入方式上实质互异；只实现被选中的一个。

## 方向 A · 「台账双栏」

```
┌ 头部任务带：目标 · 阶段 · 运行控制 · 授权徽章 ──────────────────┐
├───────────────────────────┬────────────────────────────┤
│ 对话流（1fr，档案式条目）    │ 台账侧栏（~360px，堆叠）      │
│  用户指令 slip              │  ① 审批卡（置顶）            │
│  Jarvis 条目（推理/工具/结论）│  ② Artifact tabs            │
│  系统事件线                 │  ③ 工具队列 rail             │
│ ├ Composer 常驻 ───────────┤  ④ 未验证项                  │
└───────────────────────────┴────────────────────────────┘
```

- 空间组织：经典主窗 + 侧栏；证据在侧栏按优先级静态堆叠。
- Artifact 进入：侧栏 tabs。
- 人工介入：侧栏顶部审批卡。
- 判断：稳妥但证据永远处于「侧栏」地位，注意力要靠用户自己扫描堆叠列表；四块堆叠容易滑向反例 B（同形卡片清单）。

## 方向 B · 「阶段跟随审阅面」（选定 ✅）

```
┌ 头部任务带：目标 · 阶段步进 · 运行控制 · 授权徽章 ─────────────────┐
├────────────────────────────┬───────────────────────────┤
│ 对话流（1fr，主阅读路径）      │ 审阅面（~480/440px，随阶段重排）│
│  用户指令 slip               │ 阶段❶ 等待你的决定            │
│  Jarvis 档案条目             │   · 决定区：摘要+3 决定按钮    │
│   ├ 推理摘要（折叠）          │   · Diff 证据：摘要⇄完整 一步   │
│   ├ 工具 chips（点击联动→）   │   · 验证：vitest 排队/运行/通过 │
│   └ 结论                     │   · 未验证项（常驻显式）       │
│ ├ Composer 常驻 ────────────┤ 阶段❷ 验证中 → 阶段❸ 终局      │
└────────────────────────────┴───────────────────────────┘
```

- 空间组织：一桌两椅——对话与证据并置，审阅面标题与内容随任务阶段演进（等待决定 → 验证中 → 终局·verified）。
- Artifact 进入：常驻审阅面 + 消息内工具 chips 点击联动（一步直达且高亮）。
- 人工介入：决定区永远在审阅面第一屏（Tutti 辅锚点）；暂停会真实挂起验证链（审批后 vitest 等「继续」才跑）；终止两击确认。
- 判断：同时满足「对话承担持续交互」与「产物承担最终检查」；因果关系（消息↔证据↔决定）成为界面本身；1280×800 纵向预算从容。

## 方向 C · 「横向任务带」

```
┌ 任务带（全宽）：目标 · 阶段 · 工具时间线 · 控制与徽章 ─────────────┐
├───────────────────────────────────────────────────────────┤
│ 对话流（全宽，中部）                                          │
├───────────────────────────────────────────────────────────┤
│ 审批坞（底部滑出，待审批时顶起 Composer） / Composer           │
└───────────────────────────────────────────────────────────┘
Artifact：弹出审阅浮层（临时覆盖对话）
```

- 空间组织：上下夹心，对话全宽居中。
- Artifact 进入：弹出浮层。
- 人工介入：底部审批坞与 Composer 争夺同一底边。
- 判断：800px 高度下三段纵向挤压；审批坞与 Composer 抢底部空间；浮层打开时对话被覆盖，违背「持续可见」。放弃。

## 选择与放弃理由

- **选定 B**：唯一同时满足 PRODUCT.md 三条硬要求（对话负责表达澄清 / Artifact·Diff·测试承担最终检查 / 审批·急停持续可达）的结构，且把「阶段」变成可见的空间状态而非纯文字。
- **放弃 A**：证据停在侧栏地位，静态堆叠是统计默认值；四块同区堆叠有滑向「台账看板」反例的风险。
- **放弃 C**：纵向预算在 1280×800 不成立；浮层式 Artifact 违背持续可见。

## 视觉语言（随 B 定稿）

- 材料：暖纸底（#F3EFE6 系）+ 墨色（#21201C）+ 发丝线 + 无阴影；唯一强调色朱红（#B5401F）只用于人工闸门。
- 消息形态：非气泡——Jarvis 条目=左侧朱红标线 + 分节微标签的档案块；用户=紧凑指令 slip。
- 状态不只靠颜色：全部带文字与字形（✓ ◐ ○ ✕）。
