# Jarvis 对话主导 GUI 设计笔记 (Gemini)

- **核心结构**：以单向对话时间线为主工作面；顶部 Task Anchor 常驻目标、阶段与授权判定；底部 Dock 在滚动时保持审批与终止持续可达；Reasoning、工具链、审批卡片与 Diff 原生内嵌于 Jarvis 消息流。
- **独特取舍**：
  1. **证据与审批就地内嵌**：拒绝将 Diff 与审批剥离到远端抽屉或复杂看板，将权限闸门置于调用发生处，减少注意力跳转。
  2. **双重完成判定防护**：非绿灯状态强约束显示「完成授权未授予」，仅当测试链通过才切换为「decideVerdict · verified（模拟）」。
  3. **非纯色语义状态**：状态标签统一搭载图标、代码块与结构化文本，消除单一颜色依赖。
- **实际检查**：
  1. 验证 1440×900 与 1280×800 视口下顶部 Anchor 与底部 Dock 无内容截断、交互持续可达。
  2. 验证审批 3 种决定（允许/拒绝/调整）、运行控制（暂停/终止/恢复）及场景切换状态机正常流转。
  3. 验证 prefers-reduced-motion 下动效完全降级，键盘焦点可见且支持 A/R/M/Space 快捷键。
- **已知限制**：纯前端内存模拟状态，无真实后端进程与文件系统写入；测试断言与 Diff 为静态数据预设。
