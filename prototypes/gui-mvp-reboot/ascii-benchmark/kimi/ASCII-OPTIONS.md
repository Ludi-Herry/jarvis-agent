# ASCII-OPTIONS.md · kimi 三个结构方向

## 设计问题重述（≤8 行）

- 为 Jarvis-Agent 设计单用户、本机、单任务的桌面对话工作区，1440×900 起步，1280×800 不丢关键控制。
- 首屏几秒内回答：当前目标、阶段、为什么停、用户能做什么、完成由谁授权。
- 对话是表达与澄清的主轴；Diff、测试、未验证项承担最终检查，两种阅读路径都要短。
- `workspace.write` 一次性审批、暂停/继续/终止/恢复持续可达，完成授权只来自既有验证链。
- 系统负责归组与整理（Reasoning 摘要、工具状态、证据聚合），用户不拼日志。
- 证据诚实：持久化事实、显示投影、测试、未验证项各有身份，聚合可回溯来源。
- 本轮只比信息架构与空间组织，不定配色字体，不实现页面。

## 三方向结构差异小结

- 会话/任务导航：A 无独立会话栏（顶条即任务）；B 顶部任务 tab + 历史入口；C 完全无导航，单任务单栏。
- 对话主区位置与比例：A 中央约 50%；B 下半区约 40%；C 单栏近 100%。
- 审批进入方式：A 对话内嵌卡 + 顶条锚点双通道；B 顶条/管线 → modal；C 时间线内嵌卡 + 吸顶。
- Artifact/Diff 进入方式：A 右栏常驻零步；B 上区面板常驻零步；C 抽屉一步。
- Composer 位置：A/B 底部独立固定条；C 底部 Dock 内与控制按钮同行。
- 完成授权位置：A 顶条 + 右栏双钉；B 顶条单钉；C 顶薄条单钉。
- 固定/滚动划分：A 顶/底固定 + 三栏各自滚动；B 顶/上/底固定 + 仅对话滚动；C 顶薄条/Dock 固定 + 中间整栏滚动。
