## 2. 最终选择：C · 时相推拉（Phase Shift）

C 的优势恰好压在 Jarvis 的两个不可让渡点上：人工接管（审批/暂停/终止/恢复持续可达）与对话主体性。基态对话全宽，纯度高于 A；「需要你处理」触发决定翼，把 Card 5 的首屏五问中的「为什么停下、我能做什么」空间化成一个专办区。总分差距集中在关键维度，属于方向性胜出。

**拒绝 A 的原因**：审批卡内联在对话流里，「等待你的决定」可能持续数分钟，期间决定本身会随滚动离开视口，只能靠任务条状态点作二级补偿。审批是 Jarvis 的高频人工动作，为它付「找回成本」是体验税。A 的时间线叙事被 C 继承：对话流内保留审批锚 ⌁，历史决定可回看。

**拒绝 B 的原因**：人工接管最强，代价是驾驶舱常驻吃掉约 26% 垂直空间，1280×800 下对话区被压到危险高度，且空闲时段驾驶舱信息密度极低；对话主体性滑向 PRODUCT.md 警告的监控台形态；读到消息里「停在一次性审批」需要上翻到驾驶舱做决定，阅读动线断裂。B 的横向工具时间线不带入 MVP，可作为后续增强重新评估。

## 3. 1280×800 适配（约 106 列 × 32 行）

## 4. 方案 C 规格说明

### 4.1 区域尺寸比例（1440×900 基准）

- 任务条 [F]：100% 宽 × 72px（约 8%），两行：标题行 + 状态/控制行。
- 对话 [↕]：基态 100% 宽 × 自由高（约 700px）；翼开时 62%（约 830px）。
- 决定翼 [F] 外壳：38%（约 510px）× 对话区同高；上半为决定区（固定），下半「补丁与验证」[↕] 独立滚动；Diff 全文展开时翼内临时加宽至 60% [state]。
- Composer [F]：宽度跟随对话（100% / 62%），高 88px（约 10%）。

### 4.2 固定 / 滚动归属

- 固定：任务条（含控制组与授权状态）、决定翼外壳与三决定按钮、Composer。
- 滚动：对话流（唯一长滚动）；翼内补丁与验证区 [↕]；Diff 全文 [↕] + 长行 [↔]。
- 翼开合时对话 scrollTop 与阅读锚保留；翼收起后对流内仅追加一行审批锚 ⌁。

### 4.3 首屏信息顺序

任务条（ID/目标/阶段/授权/控制）→ 决定翼（需要你处理 → 三决定 → 影响与文件 → Diff/测试/未验证项）→ 对话最新消息（自动滚到底）→ Composer。

### 4.4 键盘焦点顺序（Tab）

会话切换 ▾ → 暂停/继续 → 终止 → 恢复 → 翼内：允许一次 → 拒绝 → 要求调整 → Diff 展开 → 关翼(Esc) → 对话流最新锚（Reasoning/工具折叠组）→ Composer 输入 → 发送 → 作为调整意见。焦点环全程可见（WCAG AA）；⌘Enter 发送；Esc 关翼且焦点回对话最新锚。

### 4.5 状态变化时哪些区域变化

| 状态 | 变化区域 |
|---|---|
| 运行中 → 暂停 | 任务条切「已暂停」，控制钮「暂停」变「继续」；对话与翼位置冻结不动 |
| 允许一次 | 翼内容切「验证中」（vitest 排队 → 运行中）[state]；任务条仍 ● 需关注、授权仍 ○ |
| 验证链通过 | 任务条显示 `decideVerdict · verified（模拟）`，授权 ○ → ● [state]；翼收起；对话追加终局消息 |
| 拒绝 | 任务条切「运行失败」；翼转只读保留证据；对话追加受阻消息 |
| 要求调整 | 翼收起；Composer 载入「作为调整意见」模式 [state]，焦点入 Composer |
| 终止 | [modal] 二次确认 → 任务条切「已终止」；对话锁定只读；Composer 变「恢复此会话」入口，「恢复」高亮 |
| 恢复 | 回到终止前状态，滚动位置与阅读锚还原 |

## 5. 进入 HTML 实现前必须验证的 5 条断言

1. 翼开 → 关之后，对话容器 scrollTop 保持（同一条消息仍在视口内）；`prefers-reduced-motion` 下开合瞬时完成，所有内容不依赖动效即可见。
2. 1280×800 视口下 Composer、审批三按钮、终止控制三者同时可见，页面无横向滚动，对话可视宽度不小于约 640px（半覆盖翼）。
3. 刷新或重开后，等待中的审批能从持久化 session 重建决定翼与未验证项计数；显示投影读取失败时显式降级为来源事件，禁止静默丢弃。
4. 纯键盘可走完整链路：Tab 至「允许一次」并 Enter 等效点击，状态切「验证中」；焦点环全程可见；Esc 关翼后焦点回到对话最新锚。
5. 完成授权语义只有一个来源：任何位置出现 verified 之前，必须存在可点击的证据链路径（Diff + 聚焦命令结果 + 未验证项清零或显式列出）；「未验证项 2」这类计数与来源事件一一对应，点开可回到 JSONL 事实。
