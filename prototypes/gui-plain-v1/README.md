# gui-plain-v1 对照稿源码

2026-10-15 · 方案与签收要点见 `docs/PLAN-gui-plain-v1.md`。这是**静态演示稿**：数据全部来自 `src/scenario.ts` 的剧本，不连 Jarvis Runtime，不是正式 GUI 代码。

- 技术：Vite + React 19，`vite-plugin-singlefile` 打成一个自包含 HTML（`npm install && npm run build` → `dist/index.html`）。
- 结构：`src/App.tsx` 三栏骨架与走查台；`src/ui/` 侧栏、对话、输入框、右栏（更改 / 预览 / 终端）、走查台；`src/store.ts` 状态机与自动演示；`src/theme.css` 色彩与字体 token；`src/arc/` 只保留用到的 Arc 控件。
- 第二轮（同日）：按 PastaUI / Arc 补齐所有可点入口——左栏品牌菜单、搜索（`Ctrl K`）、项目分组折叠与「…」菜单、任务行重命名 / 归档（可撤销）、添加项目、头像菜单（外观）、设置（通用 / 外观 / 项目预览地址 / 模型与用量 / 关于）、快捷键表、顶栏重命名与「…」菜单、历史任务回放、真实的图片 / 文件附件（选择、粘贴、拖入）、预览栏刷新 / 手机宽度 / 在浏览器中打开。新文件：`src/prefs.ts`、`src/ui/{Dialogs,History,feedback}.tsx`。
- 第三轮（2026-10-16，分支 `gui-plain-v1-canvas`）：加「画布」，把整条对话链路、要做的事和进度放在一个视图里。
  - 入口：顶栏「对话 / 画布」切换（`Ctrl G`），运行中显示 `完成/总数`；左栏运行中的任务也显示进度。历史任务同样能看画布。
  - 画布顶部是一行统计：要做的事（进度环）、用时、花费 · 预算、改动文件（点开右栏更改）、检查（点开终端）。
  - 三种看法：**链路**（四条泳道 你 / Jarvis / 项目文件 / 检查 × 六个阶段 理解 → 方案 → 确认 → 修改 → 检查 → 交付，编号色带、带标签的折线箭头、悬停高亮相邻步骤、按泳道筛选、拖动平移、`Ctrl` + 滚轮缩放、适应窗口、跟随最新、图例计数；修好再跑会标出「第 2 轮」）；**状态**（任务生命周期图，实线是这次走过的路，虚线是可能的路，下方列出「这次走过的路」）；**时间**（每一步的示意时长瀑布图、花费按阶段的环形图、预算条、检查结果）。
  - 右侧：选中步骤的详情卡（Jarvis 说了什么、改了哪些文件、输出、可做的操作：允许 / 不允许 / 让 Jarvis 修好 / 接着做 / 看预览 / 看改动，上一步 / 下一步）和「要做的事」清单（每项的状态、你补充的、建议；点一项跳到对应步骤）。窄于 900px 时这两张卡排到画布下方。
  - 「讲解图」：分层拆解（设置页的爆炸等轴图，蓝色是改动层）、改动前后（同一张卡片对照 + 编号改动表）、做法（流程图，实线是这次真的走的路）；可「下载 HTML」发给别人。对话里最后一次结果下面也有讲解图卡片。
  - URL 参数：`view=canvas`、`map=flow|state|time`、`explain=layers|delta|flow`，可与原有 `state=`、`past=`、`panel=`、`theme=dark`、`dock=0` 组合。
  - 新文件：`src/canvas/{model.ts,canvas-view.tsx,canvas.css}`、`src/artifact/{explainer.tsx,explainer.css}`、`src/arc/{donut-chart,usage-meter}/`。
  - 时长与花费是按剧本估算的**示意值**，界面上标了「示意时长」，不是实测。
- 第四轮（2026-10-17，分支 `gui-plain-v1-polish`）：细节打磨 29 项（P0 1–5、P1 6–18、P2 19–29，全部做了）。参考 open-claude-ui 的原则，数值用我们自己的 token 重写，没有复制代码，没有加新依赖。
  - 边缘与圆角：一个区域只留一层闭合边缘，里面用浅底色或细分隔线；边框改成半透明细线（`--ring`、`--card-edge`，高分屏 0.5px），深色模式加一圈内侧高光；圆角整理成固定档位，内圆角 = 外圆角 − 内边距；字重改用 `--wght-*`，深色模式自动减一点。顺手修了输入框边缘：原来的细线画在 `border-beam` 外层里面，被裁掉了，现在挂在外层上。
  - 滚动：`src/ui/scroll-area.tsx`。对话离底部 40px 以内才跟随；往上翻不会被拽回去，出现「回到最新 / 有新进展」；发消息时回到底部。对话、左栏、右栏、画布侧栏的滚动区上下渐隐，贴顶 / 贴底时收起。
  - 动效：`src/ui/motion.ts` 统一入场；逐字出字改成小段模糊淡入 + 2px 呼吸光标；用户气泡轻弹入；点「允许」后审批卡原位收成「你允许了…」一行；步骤摘要带总用时，失败时自动展开第一条没通过的输出；数字变化轻跳（约 1.06 倍）；建议卡、附件、图片依次出现（每个 30ms，最多 8 个）；时长和曲线全部用动效 token，减少动效时降级。
  - 输入：中文输入法选词时按 Enter 不发送、Esc 不停止（含 Safari 的 `keyCode 229`）；窄屏和触屏输入框 16px，iOS 不再自动放大；每个任务各自保存草稿；断网时消息留在输入框上方（改一改 / 删掉 / 重发），网络恢复后提示重发。`⌘/Ctrl Enter` 在等你确认时直接允许。**修了一个 bug：以前输入框为空时按 Enter 会停止任务**，现在键盘永远不会停任务，只能点停止按钮。
  - 右栏：可以拖动调宽（4px 内的手抖不算、双击或 Enter 复位、Esc 取消、方向键微调、拖到很窄自动收起、记住宽度，拖动时预览页不吞鼠标）；复制按钮原地变勾，提示只在失败时出现；改动支持「单栏 / 并排」，并排时改之前和改之后逐行对齐，面板不够宽会自动放宽，窗口太窄会提示。
  - 画布：以鼠标为中心缩放，滚轮 / 触控板速度跟手，接近 100% 吸附；侧栏加「产物」卡（三种讲解图、改动、预览、终端，还没有的置灰）；讲解图弹窗从点开的位置放大出来。
  - 左栏：任务可以拖动排序（`Alt ↑/↓` 也行，按项目记住）；搜索里按状态筛选（全部 / 进行中 / 等我处理 / 已完成，带数量）；`↑ ↓ Home End` 切换。状态标记统一：思考 = 思考球、执行中 = 转圈、等你 = 闪烁点、没通过或没做完 = 静止点、加载 = 扫光。
  - 其他：图片点开在应用内看大图（从缩略图放大、以鼠标为中心缩放、双击 2 倍、拖动、`← →` 切换、Esc 关闭后焦点回到缩略图）；顶栏、输入框、右栏按自身宽度收起文字（container query）；触屏上小按钮的点击区域扩大；长路径和链接自动断行；焦点环改成「2px 间隙 + 2px 外环」两层。
  - Arc 改动（文件里已注明是 Jarvis 的修改）：Button 的 secondary / danger 改成浅底无边框；Dialog 内容框边框改成细线，新增 `origin` 参数，用来从点开的位置放大。
  - 新文件：`src/ui/{scroll-area.tsx,motion.ts,PanelResizer.tsx,drafts.ts,Lightbox.tsx,sortable.ts}`。
- 来源：PastaUI 布局与输入框形态；Arc（uiarc.dev 免费组件，MIT；这轮新引入 `donut-chart`、`usage-meter`，改成中文文案、加金额前缀、配色改用 `--series-*`，文件头已注明）；`thinking-orbs`、`border-beam`（均 MIT）。画布的结构参考 archify（MIT：泳道、编号阶段带、图例计数、底部工具栏、步骤详情卡、生命周期图、「示意时长」瀑布图），讲解图按 diagram-design（MIT：爆炸等轴图的 2:1 投影、单一强调色、右侧标注列、编辑式排版）的规范手画；AI Elements（Apache-2.0）只参考了 Queue / Test Results / Context 的信息组织，没有拷代码；React Flow 评估过，没有引入（自己画的 SVG 够用，单文件更小）。

## 2026-10-21 描边整合

容器边线统一使用真实 CSS border，--ring / --ring-strong 负责颜色，--hairline 负责宽度；--card-edge / --composer-edge 只负责投影和深色内高光。失败、警告、hover 与 focus 改 border-color，保留焦点光晕、拖入状态与 BorderBeam 动画。输入框边框仍挂在外层 .beam；底托保留 f0d1f4f 的 border-top:0，避免重边。

整合 3438bc0 的阴影裁切修复：底部留出 44px、画布工具栏底部留出 30px，窄屏压缩阴影外扩。8cb3d69 与 f0d1f4f 是相同补丁，不重复合并。对应 Figma 使用 INSIDE stroke。历史第四轮描述保留为变更记录，以本节为当前实现。

## 2026-10-21 动效与默认状态

审批卡收起采用真实 height 过渡，由 ResizeObserver 测量当前内容，避免 layout=size 对退场图标造成约 12 倍纵向拉伸。保留淡入淡出与收起动效；减少动态效果时高度直接切换。走查台每次打开原型默认收起，点击顶部胶囊后展开。
